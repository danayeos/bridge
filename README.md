# Bridge — уроки, посещаемость и оплаты

Внутренний сайт школы Bridge для администраторов и учителей.

- **Учитель** видит свои уроки на день. Он отмечает «Урок прошёл» (кто был, кого не было), «Перенос» (на какую дату, из-за кого, причина) или «Отмена».
- **Администратор** видит, кому пора писать об оплате (остался 1 урок), должников и пропуски. По пропуску он решает, сгорает урок или нет, и ставит штрафы учителям. Ещё у администратора есть ученики, группы, журнал уроков, отчёт о деньгах и зарплаты учителей.

## Посмотреть демо (без базы данных)

Откройте `index.html` двойным щелчком и нажмите **«Посмотреть демо»**. Данные выдуманные и пропадают после обновления страницы.

## Подключить настоящую базу данных (один раз, ~10 минут)

1. Зарегистрируйтесь на **https://supabase.com** (через GitHub или Google) и нажмите **New project**.
   Регион — Frankfurt или Mumbai. Пароль базы сохраните где-нибудь. Тариф — **Free**.
2. Откройте **SQL Editor → New query**, вставьте весь файл `supabase/schema.sql` и нажмите **Run**.
   Должно появиться «Success».
3. **Authentication → Sign In / Providers → Email**: выключите **Confirm email**.
   Иначе каждому учителю придётся подтверждать почту по письму.
4. **Project Settings → API**: скопируйте **Project URL** и ключ **anon public**
   (может называться «publishable key») в файл `js/config.js`.
5. Откройте `index.html`, нажмите «Нет аккаунта? Создать» и зарегистрируйтесь.
   **Самый первый аккаунт автоматически становится администратором.**
6. Учителя регистрируются сами. Администратор открывает «Учителя» и нажимает «Это учитель».

## Порядок работы

1. «Группы» → создать группы (курс, учитель, расписание, оплата учителю за урок).
2. «Ученики» → «Новый ученик» → «Добавить курс»: в группу или индивидуально.
   Там же указываются пакет (8 или 12 уроков), цена и сколько уроков уже оплачено.
3. Учителя каждый день отмечают уроки.
4. На «Главной» видно, кому писать в WhatsApp. Когда ученик оплатил, нажмите «Оплатил».
   Оставшиеся уроки прибавляются к новому пакету.

## Правила подсчёта

| Ситуация | Урок списывается? |
|---|---|
| Ученик был | да |
| Не пришёл, **группа** | да (сгорает автоматически) |
| Не пришёл, **индивидуально** | решает администратор: «Сгорает» или «Перенос» |
| Отмена по вине **ученика** | решает администратор |
| Перенос (любой) | нет, урок переходит на новую дату |
| Отмена или перенос по вине **учителя** | нет; администратор может поставить учителю штраф |

- **Напоминание об оплате** появляется, когда остался 1 урок или меньше. «Сопровождение» напоминаний не получает.
- **Зарплата учителя** — сумма ставок за проведённые уроки минус штрафы. В «Журнале» для любого урока можно выбрать «платить / не платить».

## Выложить в интернет бесплатно (GitHub Pages)

1. Создайте репозиторий на github.com (например, `bridge`) и загрузите туда всю папку.
2. Repository → **Settings → Pages** → Source: **Deploy from a branch**, ветка `main`, папка `/ (root)`.
3. Через минуту сайт будет доступен по адресу `https://ВАШ-ЛОГИН.github.io/bridge/`.

Ключ в `config.js` можно хранить в открытом виде, он для этого и предназначен: доступ к данным защищают правила в базе. Учитель не видит цен и оплат, а человек без подтверждённого аккаунта не видит ничего.

Бесплатный Supabase «засыпает», если сайтом не пользоваться 7 дней подряд. Тогда зайдите на supabase.com и нажмите **Restore project**, данные сохраняются.

## Файлы

- `index.html` — страница сайта
- `css/style.css` — дизайн (бордовые цвета вверху файла)
- `js/config.js` — подключение к Supabase
- `js/app.js` — вход и меню
- `js/pages/*.js` — страницы (главная, расписание, ученики, группы, учителя, журнал, деньги)
- `js/logic.js` — расписание и расчёты
- `js/demo.js` — демо-режим
- `supabase/schema.sql` — база данных и права доступа
